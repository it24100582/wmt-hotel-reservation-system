# WMT Team Responsibility

## Team Member 1 - Mobile Frontend Developer
- Build React Native screens and navigation flows.
- Integrate API services for auth, rooms, and bookings.
- Ensure responsive UI/UX and error handling on Android/Web.
- Maintain Admin dashboard mobile interface.

## Team Member 2 - Backend API Developer
- Build Node.js + Express REST APIs.
- Implement controllers, middleware, validation, and RBAC.
- Maintain route structure and endpoint consistency.
- Integrate file upload and admin operations.

## Team Member 3 - Database & Data Modeling Engineer
- Design MongoDB collections and Mongoose schemas.
- Define ObjectId relationships and indexes.
- Implement seed/init scripts for hotel data collections.
- Support migration from SQL table structure to MongoDB.

## Team Member 4 - QA, Documentation & DevOps Support
- Test API endpoints and frontend workflows.
- Validate authentication, booking lifecycle, and admin operations.
- Prepare submission documents and diagrams.
- Support environment configuration and deployment readiness.

## Shared Responsibilities
- Weekly progress reviews and integration testing.
- Git collaboration, pull request reviews, and issue tracking.
- Final demo preparation and assignment report alignment.
