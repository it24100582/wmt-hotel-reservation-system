# Export Guide for Final Submission Files

## Target Required Files
- `Problem_Statement.pdf`
- `System_Architecture_Diagram.png` (or `.pdf`)
- `Database_Schema_Diagram.png` (or `.pdf`)
- `API_Endpoint_Table.pdf`
- `Team_Responsibility.pdf`

## Source Files Created
- `submission_docs/Problem_Statement.md`
- `submission_docs/System_Architecture_Diagram.mmd`
- `submission_docs/Database_Schema_Diagram.mmd`
- `submission_docs/API_Endpoint_Table.md`
- `submission_docs/Team_Responsibility.md`

## How to Export Quickly
1. Open each `.md` file in VS Code preview and print to PDF (`Ctrl+P` -> `Save as PDF`).
2. Open each `.mmd` file in a Mermaid editor and export as PNG or PDF.
3. Rename exported files to exactly match the target required filenames.
