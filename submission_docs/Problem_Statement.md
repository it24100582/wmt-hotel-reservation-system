# WMT Hotel Room Booking and Reservation System

## 1. Background
The WMT project is a full-stack hotel room booking and reservation platform designed to modernize room discovery, reservation workflows, and hotel operations management. The system supports both guest users and administrators.

## 2. Problem Statement
Many hotel booking processes are still fragmented across calls, spreadsheets, and manual approvals. This creates operational delays, booking conflicts, and limited visibility for both guests and staff.

WMT addresses this problem by providing:
- A mobile-first user experience for account creation, room browsing, and reservations.
- A centralized backend API for booking lifecycle management.
- MongoDB-based persistence for scalable hotel data management.
- Admin capabilities for room control, booking approvals, and user management.

## 3. Project Objectives
- Build a reliable hotel reservation system using React Native, Node.js/Express, and MongoDB.
- Provide secure authentication and role-based access control.
- Enable complete booking CRUD and approval flows.
- Support operational modules such as pricing, housekeeping, maintenance, inventory, contact handling, and coupons.

## 4. Scope
### In Scope
- User registration and login
- Room listing and room detail retrieval
- Booking creation and cancellation
- Admin approval/rejection of bookings
- Admin room and user management
- Image upload for room assets
- MongoDB schema design for major hotel operations collections

### Out of Scope (Current Phase)
- Payment gateway integration
- Advanced analytics and BI reporting dashboards
- Multi-hotel/multi-branch tenancy

## 5. Stakeholders
- Hotel guests (end users)
- Hotel administrators
- Hotel operations staff (housekeeping, maintenance, inventory teams)
- Project development team

## 6. Expected Outcome
WMT delivers a production-ready foundation for a hotel reservation platform with extensible backend architecture and mobile interface support, reducing manual effort and improving booking accuracy and operational responsiveness.
